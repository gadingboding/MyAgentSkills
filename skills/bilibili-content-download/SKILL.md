# 哔哩哔哩内容下载与图文导出

本技能支持哔哩哔哩视频下载与动态/专栏图文导出为 PDF 文件。

## 动态与专栏导出 PDF

通过内置脚本 `scripts/fetch-opus-pdf.py` 抓取指定哔哩哔哩动态或专栏的文字与图片，并生成 PDF 文件。

### 执行流程

1. 从任务上下文中获取哔哩哔哩动态或专栏链接（如 `https://www.bilibili.com/opus/...`）或 ID。
2. 确定输出的 PDF 文件路径（若父目录不存在脚本会自动创建）。
3. 执行导出脚本：

```bash
python3 skills/bilibili-content-download/scripts/fetch-opus-pdf.py "<动态或专栏链接/ID>" "<输出PDF路径>"
```

### 结果检查

1. 确认命令正常退出（退出码为 0）。
2. 确认生成的 PDF 文件存在且大小大于 0。

## 视频下载

使用 `uvx` 临时运行 `yt-dlp`，无需预先安装 `yt-dlp`。默认下载不高于 480P 的最佳视频流和最佳音频流，并将两者合并为 MP4 文件。

下载哔哩哔哩视频时，不使用任何代理。

### 下载流程

1. 从当前任务上下文、已有页面、消息或上一步结果中确定哔哩哔哩视频链接。若没有直接链接，但目标视频可被唯一识别，则先通过可用的检索或浏览能力定位其链接；只有无法确定具体视频时才向用户询问。
2. 用户未指定输出目录时，优先将视频保存到当前agent会话的临时目录中。执行下载前确保目录存在，不要覆盖已有文件。
3. 直接执行下载命令，不要预先检查用户是否安装了 `ffmpeg`：

```bash
uvx --from yt-dlp yt-dlp \
  --proxy "" \
  --format "bestvideo[height<=480]+bestaudio/best[height<=480]" \
  --merge-output-format mp4 \
  --remux-video mp4 \
  --no-overwrites \
  --output "<会话临时目录>/%(title).200B [%(id)s].%(ext)s" \
  "<哔哩哔哩视频链接>"
```

若用户指定输出目录，只修改 `--output`，例如：

```bash
--output "<输出目录>/%(title).200B [%(id)s].%(ext)s"
```

仅当当前任务明确要求其他清晰度、字幕、分集范围、登录态或文件命名方式时，才调整相应参数。需要登录态时，可按任务上下文中指定的浏览器增加 `--cookies-from-browser <浏览器>`。

### 结果检查

下载命令成功后，必须检查最终文件，而不能只依据下载进度判断成功：

1. 确认 `yt-dlp` 命令以成功状态退出，并且输出中没有合并或转换失败的信息。
2. 找到本次命令生成的最终文件，确认文件存在、大小大于 0，且扩展名为 `.mp4`；不要执行 `ffprobe`。
3. 若下载、合并、转换或结果检查失败，使用相同配置重试一次。总共最多执行两次，不要持续重试。
4. 第二次仍失败时，保留最后一次的原始错误信息并说明未能确认合并成功；不要把仅有视频、仅有音频、临时分片或非 MP4 文件报告为成功结果。
5. 若下载是中间步骤，将已确认的 MP4 路径交给后续步骤继续处理；若下载是最终交付内容，再向用户报告文件路径、清晰度上限为 480P，以及容器格式为 MP4。
