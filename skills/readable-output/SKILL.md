# 输出内容的语言规范

在输出用户可读内容时，**必须**考虑到内容的可读性，改善用户的阅读体验，具体来说有下面几个目标：
1. 符合目标语言的语法结构，绝不出现使用结构异常的句子，合理考虑句子和段落的组织
2. 使用合理的目标语言词语，不要使用英文直译的词语，导致阅读起来非常奇怪
3. 防止过度跳跃的逻辑，注意句子的前后关系是可读性的另外一个关键

注意：上面的要求是针对输出内容的语言规范，而不是对具体输出内容的规范
